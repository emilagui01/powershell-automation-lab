# PowerShell Automation Lab

*Home Lab 3 of 3 · **Complete** · [view all labs](https://emilagui01.github.io/#labs)*

Three PowerShell scripts that run the account lifecycle of the Active Directory domain from [Lab 1](https://emilagui01.github.io/ad-homelab/): bulk onboarding from a CSV, safe offboarding, and an account health report. Each real run is tied to a ticket on the [Lab 2](https://emilagui01.github.io/helpdesk-lab/) osTicket help desk, and the ticket number is written onto the account in AD.

**Live writeup:** https://emilagui01.github.io/powershell-automation-lab/
**Portfolio:** https://emilagui01.github.io/#labs

## Scripts

| Script | What it does |
|---|---|
| [New-LabUsers.ps1](New-LabUsers.ps1) | Creates accounts from a CSV: validates rows, skips existing people, builds unique usernames, places users in department OUs and groups, creates a private H: drive, logs everything |
| [Remove-LabUser.ps1](Remove-LabUser.ps1) | Offboards without deleting: refuses protected accounts, records groups, disables, resets the password, removes groups, moves to Disabled Users, archives the home folder |
| [Get-LabUserReport.ps1](Get-LabUserReport.ps1) | Read-only report of locked out, disabled, never-used and password-problem accounts, as HTML and CSV |

All three support `-WhatIf`, log every action, and handle errors per user so one failure doesn't stop a batch.

```powershell
.\New-LabUsers.ps1 -CsvPath .\NewHires-520879.csv -Ticket 520879 -WhatIf
.\Remove-LabUser.ps1 -Identity wmaximoff -Ticket 125558
.\Get-LabUserReport.ps1 -ExpiringDays 45 -Open
```

## Results

- [x] 15 accounts created from an 18-row CSV; 3 bad rows refused (two unknown departments, one existing account); `jsmith` collision became `jsmith2`
- [x] Second run of the same CSV: 18 skipped, no duplicates
- [x] New user signed in, was forced to change password, and got H: and S: with Control Panel blocked
- [x] Offboarding refused `Administrator`, skipped a non-existent user, and fully offboarded two users without deleting anything
- [x] Report found a lockout, confirmed it cleared after `Unlock-ADAccount`, and surfaced two accounts whose password never expires
- [x] Ticket #520879 (New Hire Request) and #125558 (Employee Offboarding) worked end to end; accounts searchable in AD by ticket number
